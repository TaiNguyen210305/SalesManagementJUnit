# Sales Management System

![Sales Management System CI](https://github.com/TaiNguyen210305/SalesManagementJUnit/actions/workflows/maven.yml/badge.svg)

## Description

Sales Management System project using Java, Maven and JUnit for Unit Testing.

The project includes Continuous Integration (CI) using GitHub Actions.

## Technologies

- Java 17
- Maven
- JUnit
- GitHub Actions

## Continuous Integration

GitHub Actions automatically performs:

- Checkout source code
- Set up JDK 17
- Build the project with Maven
- Run Unit Tests
- Package the application

## Run Tests

```bash
mvn test
